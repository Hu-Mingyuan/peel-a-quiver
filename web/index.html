Peel a quiver

Peel each quiver down to the empty quiver using mutations, removing sinks and sources, and, if needed, adding auxiliary nodes.

Rules

Based on Bernhard Keller's quiver mutation applet and the paper Ice and mirrors.

Rules

Goal. Peel the quiver down to the empty quiver.

Moves.

  • Mutate: click a vertex k to mutate there. For each path i→k→j add an arrow i→j, reverse all arrows at k, then cancel 2-cycles.
  • Peel: drag a sink or a source into the trash can (top right of the board) to delete it. A vertex is a sink if every arrow at it points in, and a source if every arrow at it points out; an isolated vertex is both. Sinks are blue, sources orange, isolated vertices green.
  • Add node: click an empty spot to place a new vertex (dashed). Then, as in Keller's applet, click a source and then a target to add one arrow; adding an arrow in the opposite direction cancels one. Every arrow must touch the new vertex. Press Done when finished. Arrows between existing vertices cannot be changed.

Controls. Drag a vertex to move it. Undo (also Ctrl/⌘+Z) takes back one step, Restart resets the level, ← Levels returns to the level list. Several parallel arrows are drawn as one arrow labelled with their number.

Create your own. The last card on the level list opens an editor. Click an empty spot to add a vertex, use Add arrow to connect vertices (click a source, then a target; an arrow in the opposite direction cancels one), and Delete vertex to remove one. Press Start peeling to play your quiver with the same rules, and Edit quiver to go back to the editor. Share link gives a link that opens your quiver for anyone.

When is a level solvable? Exactly when its quiver is sub-peelable, i.e. a full subquiver of a quiver that can be peeled using mutations and sink/source removals alone (a peelable quiver). Without adding nodes, a level is solvable exactly when its quiver is peelable.
