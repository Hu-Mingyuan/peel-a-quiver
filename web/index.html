Peel a quiver

Peel each quiver down to the empty quiver using mutations, removing sinks and sources, and, if needed, adding auxiliary nodes.

Based on Bernhard Keller's quiver mutation applet.

sink source isolated (both sink and source) auxiliary node
Rules

Goal: peel the quiver down to the empty quiver.

  • Mutate: click a vertex to mutate there. For each path i→k→j add an arrow i→j, reverse all arrows at k, then cancel 2-cycles. Dragging a vertex only moves it.
  • Peel sink/source: click a coloured vertex (a sink or a source) to delete it.
  • Add node: click an empty spot to place a new vertex, then, as in Keller's applet, click a source and then a target to add one arrow; adding an arrow in the opposite direction cancels one. Every arrow must touch the new vertex. Press "Done" when finished.

The quiver can be peeled ⇔ it is sub-peelable. It can be peeled without adding nodes ⇔ it is peelable.
